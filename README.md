# Мини-система денежных переводов на Go

Система денежных переводов между пользователями на структурах, методах, интерфейсах и горутинах.

## Как запустить

`go run .`

## Как собрать

`go build .`

## Ветки

-   `v1` - создание пользователей и выполнение простых транзакций
-   `v2` - добавление транзакций и обработка нескольких пользователей
-   `v3` - добавление конкурентности и обработка транзакций используя горутины
-   `v4` - реализация конкурентного доступа и предотвращение data race condition
